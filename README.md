# multimodal-video-classification
small research experiment classifying different categories of videos

## Third-Party Models

This project uses the following pretrained models:

- VideoMAE Base — MCG-NJU/VideoMAE
- KVAE-Audio — Kandinsky Lab

The pretrained models are used for feature/latent extraction. No
pretrained model weights are included in this repository.

Please see the respective upstream repositories for licensing,
attribution, and citation information.
